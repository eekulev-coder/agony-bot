# 🏴 Fam Bot — Discord бот для крайм-фамы GTA 5 RP

Дискорд-бот для мафии на GTA 5 RP с системой тикетов, логами и мониторингом битв.

## 📋 Функционал

### 🎫 Тикеты
- Панель регистрации тикета с кнопкой
- Автосоздание приватного канала
- Транскрипт в `.txt` при закрытии
- Лимит 2 открытых тикета на человека

### 📊 Мониторинг битв (Richman)
- Автопроверка каждые 3 минуты
- Алерты **на атаку на нас** и **нашу атаку** с пингом @everyone
- История всех битв в отдельном канале
- Backfill истории за N дней

### 📝 Логи сервера
- Удалённые сообщения (с медиа)
- Изменённые сообщения
- Смена ников
- Выдача/снятие ролей

### 🛠️ Утилиты
- `/announce` — объявление
- `/poll` — опрос
- `/clear` — удаление сообщений

## 🚀 Установка

### Требования
- Python 3.12+
- discord.py 2.4.0+

### 1. Клонируй репозиторий
```bash
git clone https://github.com/username/fam-bot.git
cd fam-bot
```

### 2. Установи зависимости
```bash
pip install -r requirements.txt
```

### 3. Настрой `.env`
```bash
cp .env.example .env
```
Открой `.env` и заполни своими данными.

### 4. Запусти
```bash
python bot.py
```

## 📖 Команды

| Команда | Кто | Что делает |
|---|---|---|
| `/ticketpanel` | Админ | Отправить панель тикетов |
| `/announce` | Админ | Объявление с @everyone |
| `/poll` | Админ | Простой опрос |
| `/clear` | Админ | Удалить сообщения |
| `/whoattacks` | Все | Топ атакующих на нас |
| `/winrate` | Все | Винрейт мафии |
| `/backfill` | Админ | Залить историю за N дней |
| `/testalert` | Админ | Тестовое уведомление |
